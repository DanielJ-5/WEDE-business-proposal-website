## Project Overview
Stay Ease is a short-term accommodation website (similar to Airbnb) where visitors can
browse listings, enquire about a stay or about becoming a host, and contact the team.
The website was built using HTML, CSS and JavaScript, and developed across the three
parts of the Portfolio of Evidence (POE).

## Goals and Objectives
- Give guests an easy way to find and enquire about short-term stays.
- Allow property owners to enquire about listing their place as a host.
- Present a clean, mobile-friendly and search-engine-optimised website.
> _Adjust these to match the goals in your Part 1 proposal._

## Key Features and Functionality
- Multi-page layout: Home, About Us, Gallery, Products, Enquiry and Contacts.
- Enquiry form with JavaScript validation that returns a tailored availability/rate response.
- Contact form with JavaScript validation that compiles the message into an email.
- Image lightbox on the Gallery page (click an image to view it enlarged).
- Dynamic listings on the Products page that can be searched and sorted.
- On-page SEO: meta description, keywords and author tags, image alt text, and semantic headings.
